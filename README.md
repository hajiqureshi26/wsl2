# DevOps CI/CD Project

## Overview
A beginner-friendly DevOps project using Docker, GitHub Actions,
Terraform, and AWS EC2.

## Technologies
- Git and GitHub
- Docker
- GitHub Actions
- Terraform
- AWS EC2
